# Circle Clicker

Кликер-игра для Android: тыкай по кругу, копи монеты, нанимай генераторов, прокачивай улучшения, перерождайся ради бонусов.

Разработана на Flutter — APK-сборки прикрепляются к PR.

## Сборка

```bash
flutter pub get
flutter test
flutter build apk --release --split-per-abi
```

Готовые APK будут в `build/app/outputs/flutter-apk/`.
