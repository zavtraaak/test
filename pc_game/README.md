# Eternal Depths

Глубокий roguelike-RPG для ПК на Python + pygame. Создан как пример игры "на сотни часов": перманентная смерть, процедурная генерация, десятки билдов, сотни предметов и заклинаний, боссы, ачивки.

## Особенности

- 30 уровней подземелья с 8 биомами (caverns, sewers, crypt, library, forest, ice, lava, void)
- 10 рас (Human, Elf, Dwarf, Orc, Halfling, Tiefling, Dragonborn, Gnome, Vampire, Goblin)
- 13 классов (Warrior, Paladin, Mage, Wizard, Rogue, Ranger, Priest, Druid, Necromancer, Monk, Berserker, Bard, Alchemist)
- 7 базовых характеристик (STR/DEX/CON/INT/WIS/CHA/LUCK), школы магии, прокачиваемые навыки
- ~100 предметов: оружие, броня, шлемы, плащи, сапоги, кольца, амулеты, зелья, свитки, жезлы, книги заклинаний, еда, инструменты, бомбы, гемы
- ~50 заклинаний 9 школ + способности классов
- ~50 видов монстров и 6 уникальных боссов на ключевых уровнях
- Система статусов (яд, страх, паралич, кровотечение, регенерация, невидимость и т.д.)
- Алтари, фонтаны, сундуки, магазины, торговцы, квестодатели
- Идентификация, чары, проклятия, благословления, перезарядка жезлов
- Ачивки, таблица рекордов, сохранение/загрузка
- Permadeath, несколько концовок (победа над Eternal One или смерть в пути)

## Управление

```
hjkl / стрелки / numpad : движение (диагональ: yubn или цифры на нумпаде)
g       : подобрать
i       : инвентарь
e       : экипировка
r       : снять экипировку
z       : каст заклинания
Z       : спецспособности
s       : навыки
C       : лист персонажа
Q       : квесты
A       : ачивки
?       : помощь
q       : выпить зелье / напиться из фонтана
R       : прочитать свиток / книгу
o       : открыть сундук
#       : молиться у алтаря
f       : стрельба
t       : бросить
x       : осмотреться
.       : ждать ход
5       : отдых до полного
> / <   : вниз / вверх по лестнице
S       : сохранить игру
Esc     : выйти в меню (автосохранение)
```

## Запуск из исходников

```bash
pip install -r requirements.txt
python game.py
```

Требуется Python 3.10+ и pygame >= 2.5.

## Сборка .exe

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name EternalDepths game.py
# результат: dist/EternalDepths.exe (Windows) или dist/EternalDepths (Linux)
```

GitHub Actions автоматически собирает Windows-EXE на каждый PR (см. `.github/workflows/build-windows.yml`).
